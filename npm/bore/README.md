# @qinshower/bore

Deprecated compatibility package for [@qinshower/ltr](https://github.com/fishandsheep/ltr).

Existing commands continue to receive their arguments unchanged. Migrate when convenient:

```sh
npx @qinshower/ltr local 8000 --to your-server.example
bunx @qinshower/ltr local 8000 --to your-server.example
```

The Bore compatibility window is planned for two LTR major versions.
