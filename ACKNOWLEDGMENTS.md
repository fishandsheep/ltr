# Acknowledgments

LTR builds on the design and implementation of [bore](https://github.com/ekzhang/bore) by Eric Zhang and its contributors. The original project established the compact TCP relay protocol, HMAC challenge-response authentication, and Tokio-based implementation that LTR preserves for compatibility.

LTR is an independently maintained fork/rewrite. LTR additions include the Web control plane, remote Web and SSH bundle workflows, HTTPS and bearer-token controls, npm/Bun multi-platform packaging, and the `ltr` product identity.
